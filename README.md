# totem2mods 🐧

Два мода Семёна Гридина в одном репозитории.

## totemcuk
Меняет цвет узора на тотеме бессмертия. В игре: команда `/totemcuk красный` (цвета: красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, розовый, белый, чёрный или любой код `#RRGGBB`). Цвет запоминается.

**Контур тотема:** Настройки → Ресурспаки → «Totemcuk: контур тотема …» (красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, розовый, белый, чёрный). Контур обводит фигурку тотема, в том числе на картинке при срабатывании.
