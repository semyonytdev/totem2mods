# totem2mods 🐧

Два мода Семёна Гридина в одном репозитории.

## totemcuk
Перекрашивает зелёный узор на тотеме бессмертия (картинка тотема, которая выскакивает посреди экрана).
Выбор цвета: **Настройки → Ресурспаки → «Totemcuk: узор тотема …»**.
Цвета: красный, оранжевый, голубой, синий, фиолетовый, розовый, белый, чёрный. Зелёный это оригинал, ресурспак не включай.
